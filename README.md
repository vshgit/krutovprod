# KRUTOV Production — сайт

Одностраничный сайт студии (EN по умолчанию, RU переключателем). Всё в `index.html`.

**Как добавить работу:** в начале `<script>` найдите массив `WORKS` и добавьте строку:
`{cat:"music", en:"Название", ru:"Название", den:"Music video", dru:"Клип", video:"youtube:ID"}`
Категории: `music`, `ads`, `ai`, `shorts`. Работы без `video` на сайте не показываются.

Шоурил, трейлеры, ссылки на фильмы — объект `CONFIG` там же.
